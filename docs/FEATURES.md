# 大力丸 · 功能清单

> 版本 v1.0.0 ｜ 整理日期 2026-10-23 ｜ 主代码 81 个 Java 文件 / 约 1.80 万行 ｜ 单元测试 336 个
> 运行方式：Windows 绿色版（解压即用，不写注册表除右键菜单外的东西）｜ 全程离线

---

## 一、总览

大力丸是一个**本地离线**的桌面工具箱，把「临时查一下、顺手转一下」的零碎操作收在一处：
文本编解码、摘要、加解密、二维码、OCR、图片信息，以及 Office / PDF / 图片之间的互转。

- **不联网**：没有账号、没有云端、不上传任何内容
- **不依赖外部程序**：Office ⇄ PDF 双向转换、OCR 都内置引擎，装好就能用（保真度见「已知限制」）
- **一个窗口装下 18 个功能**，左侧分组导航，可按需隐藏不用的页面（隐藏项收在底部「更多」里，不是删掉）
- **它也能被别的程序调用**：右键菜单、命令行都能触发转换

## 二、功能清单（按界面导航顺序）

### 1. JSON 工具

把「格式化」「树视图」「表格」合成一页，同一份内容在三种形态间切换，不会出现两处内容不一致。

| 功能点 | 说明 |
| --- | --- |
| 格式化 | 缩进可选 2 空格 / 4 空格 / Tab，一键美化 |
| 压缩 | 去掉所有多余空白与换行，压成单行 |
| 语法校验 | 输入停止 250 ms 后自动校验，标出错误位置与原因（512 KB 以内实时） |
| 大文件编辑框 | 虚拟滚动 + 行号 + 语法着色：20 万字符以内整篇着色，超过只给可见行着色、滚动停下 60 ms 后补算；80 万字符 / 4.4 万行加载约 0.13 s |
| 树视图 | 把 JSON 摊成可折叠的节点树，显示每层的类型与值 |
| 删除节点 | 右键节点可「删除此节点」，连同子树一起移除、立即生效不弹确认；改的是文本并按原缩进写回，根节点不可删 |
| 表格视图 | 对象数组转成表格：列取所有键名的并集、缺字段留空、第一列行号；嵌套对象与数组还原成紧凑 JSON 放在单元格里，不展开成 `a.b.c` |
| 自动找数据 | 不必自己挑数组：包裹结构（`{"code":0,"data":{"list":[…]}}`）会自动下钻到最像表格的那段数组，对象数组优先，其次列多、行多、层级浅，状态栏写明「数据来自 data.list」 |
| 切换数据源 | 全文不止一处数组时，状态栏出现「数据源」下拉，列出所有候选数组，点开即切，无需改 JSON |
| 导出 Excel / CSV | 默认导出 `.xlsx`（fesod 写出，数字列自动转数值、表头 11 号字白底、按内容自动列宽、工作表名取数据源路径）；CSV 仍保留（带 BOM 的 UTF-8，Excel 打开不乱码）；超过 5000 行 / 200 列只渲染一部分并在状态栏说明 |
| 展开 / 折叠全部 | 一次到位，长文档定位字段快 |
| 右键菜单 | 复制路径（`data.list[0].name`）、复制键名（不带引号）、复制值（字符串去引号）、删除此节点 |
| 复制 value | 复制字符串值时自动去掉外层双引号，黏贴直接用 |
| 拖入文件 | 直接拖 `.json` 文件进来（8 MB 以内），读盘与建树都在后台线程 |
| 示例 / 清空 | 一键填充示例数据、清空输入；表格视图下的示例是一份接口包裹结构，能直接看到自动定位的结果 |
| 快捷键 | `Ctrl + Enter` 按当前视图刷新（文本态格式化） |

### 2. MyBatis SQL

把 MyBatis DEBUG 日志里的 `Preparing` / `Parameters` 两行还原成能直接执行的 SQL。

| 功能点 | 说明 |
| --- | --- |
| 日志还原 | 粘整段日志（带时间戳、Logger 名都不影响），按顺序把 `?` 换成实际参数 |
| 类型还原 | 按日志里的类型决定引号：`01(String)` → `'01'`、`1(Long)` → `1`、`null` → `NULL`，时间戳自动去掉 `.0` |
| 多语句 | 一次粘贴多段日志（例如批量 insert），多条之间补分号，可直接整段执行 |
| 集合展开 | `[11, 22](ArrayList)` 按元素展开，对上 foreach 生成的多个 `?` |
| 转义 | `O'Brien` → `'O''Brien'`；字符串与注释里的 `?` 不会被当成占位符 |
| 格式化 | 内置 sql-formatter，5 种方言（MySQL / PostgreSQL / Oracle / SQL Server / 标准 SQL），关键字可大写，也可关掉只填参 |
| 语法着色 | 结果区带行号，关键字 / 函数 / 字符串 / 数字 / 注释分色；明暗主题各一套配色，复制出去仍是纯文本 |
| 来源标注 | 状态栏显示日志来自哪个 Mapper 方法，如 `getUserList.debug(159)` |
| 容错提示 | 参数与 `?` 数量不一致时，指出是哪条语句、差几个 |
| 拖入文件 | `.log` / `.txt` 直接拖进来，UTF-8 与 GBK 都能读 |
| 快捷键 | `Ctrl + Enter` 立即拼接 |

### 4. Base64（文本 / 图片）

一页两种模式，顶部「文本 / 图片」切换。两者本质是同一件事，只是字节来源不同：文本按所选字符集取字节，图片取文件字节并额外识别 mime。拆成两个导航项，等于让人在两个页面之间来回找。

**文本模式**

| 功能点 | 说明 |
| --- | --- |
| 编码 / 解码 | 文本与 Base64 互转 |
| URL-safe | 支持 `-_` 变体且自动处理无填充的情况 |
| 字符集 | 可选文本编码（UTF-8 等），避免中文乱码 |

**图片模式**

| 功能点 | 说明 |
| --- | --- |
| 图片 → Base64 | 选图或拖入后立即编码，可在「纯 Base64」与「带 `data:image/png;base64,` 前缀」之间切换 |
| 格式判定 | 以文件头（magic）为准、扩展名兜底——把 `.png` 改名成 `.jpg` 也能给出正确 mime |
| 预览与信息 | 左侧显示图片、文件名、体积与识别出的类型；状态栏给出「原体积 → 字符数」与膨胀倍数 |
| 大图保护 | 单文件上限 16 MB；输出区只渲染前 20 万字符，复制拿到的仍是完整内容 |
| 折行显示 | 长串按窗口宽度折行，不用横向拖动；折行只在显示层，复制与 `getText()` 仍是连续单行 |
| Base64 → 图片 | 粘贴 Data URI 或纯 Base64（可带换行），点「解码预览」显示图片与建议扩展名 |
| 另存为 | 按嗅探出的格式给默认文件名（`.png` / `.jpg` / `.gif` / `.webp` / `.svg` …） |
| 只认图片 | 解出来不是图片时明确报错，不会把一段二进制当成图片存下来 |
| 无法预览时 | SVG 这类 JavaFX 渲染不了的格式给出说明，但字节本身完整、仍可保存 |

两个模式共用一个「清空」；在文本模式下把图片拖进窗口，会自动切到图片模式并开始编码。

## 三、全局能力

| 能力 | 说明 |
| --- | --- |
| 主题 | 跟随系统 / 浅色 / 深色三态循环切换，选过就记住；跟随系统时窗口重新获得焦点会重探 |
| 界面设置 | 17 个页面里不需要的可以逐个隐藏，保存后左侧导航立即刷新；隐藏项不会被删掉，会收进侧栏底部的「更多（N）」里，点开在导航末尾展开「已隐藏」一组，随时可以再进去 |
| 还原默认值 | 页脚「恢复默认」一键把本页开关拨回初始状态：导航项全显示、系统集成两项全关；确认用页内遮罩卡片（点外侧或 `Esc` 取消），只改界面，点「保存」才写入并走同一条路径清理注册表；主题由右上角按钮控制，不受影响 |
| 关于 | 顶栏设置按钮旁的 ⓘ 弹窗：版本（jar 清单读取）、Java 运行时与系统、配置文件路径、「本地运行不联网」、第三方组件及许可（Stirling=MIT、其余 Apache-2.0 / BSD-2 等，未声明的写「宽松开源许可」）；「复制版本信息」一键复制排障信息，`Esc` 关闭；数据在 `core/AppInfo`，可单测 |
| 系统集成 | 资源管理器右键菜单，两个独立开关，右键里**只多一个「大力丸」子菜单**：<br>① **Office 转 PDF**：16 种 Office 后缀上展开为「转 PDF」；<br>② **PDF 转 Office**：`.pdf` 上展开为「转 Word / 转 Excel / 转 PPT / 提取文本」四项，分别产出 `.docx` / `.xlsx` / `.pptx` / `.txt`。<br>都只写 HKCU、可开关、程序目录搬家后启动时自动重写；级联用 `SubCommands` 空值 + 父键 `Shell` 子键，并同时写 `ExtendedSubCommandsKey` 集中键双保险 |
| Win11 一级菜单 | Win11 把传统菜单项收进「显示更多选项」，可一键换回经典菜单（HKCU 下写一个空 `InprocServer32`，重启资源管理器生效，可随时撤销）。**这是全局改动**：所有程序的右键都变成 Win10 长菜单，所以默认关闭、勾选后保存时再确认一次；不改样式时 `Shift + 右键` 也能直接调出 |
| 单实例聚合 | 右键连续点多个文件时，用本地套接字（`127.0.0.1` 随机端口）把请求并到已开实例，不重复起进程；只借进程不改界面 |
| 结果卡片 | 无论程序开着还是没开，都在右下角弹同一张自绘卡片：圆角 + 阴影 + 淡入，配色跟随主题，12 秒自动关闭、鼠标移入暂停 |
| 拖放 | JSON、Base64、哈希摘要、Office 转 PDF、图片信息、OCR、图片转 PDF 七页支持把文件直接拖进来；Base64 页拖入图片会自动切到图片模式 |
| 一键复制 | 所有结果区都有复制按钮，字符串类结果自动去掉引号 |
| 命令行 | `大力丸.exe --to-pdf "D:\a.pptx"` 可被脚本或其他程序调用；主窗口开着时也只做后台转换，不改窗口状态 |
| 后台执行 | 读盘、解析、转换、识别都在后台线程，界面不卡；连续操作会丢弃过期结果 |
| 本地记录 | `~/.daliwan/` 下：`settings.properties`（偏好）、`instance.port`（单实例通道）、`convert.log`（转换日志）、`dnd.log`（拖放耗时）、`theme.cache`（主题） |
| 离线 | 不发起任何网络请求 |

## 五、已知限制

| 限制 | 现状与原因 |
| --- | --- |
| `.wps` 不再支持 | Stirling 引擎不支持 WPS 私有格式，可转换列表已移除；需要时先用 WPS 另存为 docx |
| PDF 转 Office 只是「近似还原」 | 反解得到的是可编辑内容（段落 / 标题 / 列表 / 表格），不是版式的像素级复刻：多栏混排、艺术字、手写批注、复杂表格合并单元格会退化；扫描件（图片型 PDF）没有文本层，转出来是空的，要先走 OCR |
| PPT 在受限环境会失败 | 评估版 Slides 初始化时要调 `reg.exe` 读 Shell Folders 定位字体，被安全策略禁用 reg 的机器上会报错 |
| 图片转 PDF 无版式选项 | 每页就是图片原始尺寸，没有 A4 适配、页边距、统一页面尺寸，打印会大小不一 |
| PDF 能力偏基础 | 只有拆分与合并，没有压缩、加密、页面旋转 / 删除 / 重排、加水印、提取图片 |
| 图片能力有限 | 能查看元数据、去除元信息；没有压缩、格式转换、裁剪、加水印 |
| 去除元信息的格式边界 | JPEG / PNG / WebP / GIF 走无损剪裁，BMP / TIFF 退回重编码（画质与体积会有变化）；HEIC / RAW 需要专门解码器，暂不支持，会提示先转成 JPEG 或 PNG |
| SQL 只认日志形态 | MyBatis SQL 页处理的是已经绑定好参数的 `?` 日志；`#{}` 模板与 `<if>` / `<foreach>` 动态标签不在此页展开 |
| 拖放不统一 | PDF 拆分合并、二维码识别、文本比对这三页目前只能点按钮选文件 |
| Win11 一级菜单靠“换样式”实现 | 绿色版没有 MSIX 包标识，进不了 Win11 新版一级菜单。开关的实际做法是把整个系统的右键换回 Win10 经典菜单（往 HKCU 写一个空 `InprocServer32`），所以所有程序、所有文件的右键都会变样，不只是本软件；默认关闭，勾选后保存时再确认一次，可随时撤销 |
| 大文本有上限 | JSON 实时校验 512 KB 内生效，拖入文件上限 8 MB；文本比对 6000 行以内做精细 diff |
| 单行大 JSON 暂停着色 | 一整行的压缩 JSON 超过 8 000 字符时自动停掉语法着色（否则 RichTextFX 要按几万个样式段重排整行，15 万字符实测卡 10 秒、之后每敲一个字都卡），状态栏提示点「格式化」展开后恢复；多行文档不受影响 |
| 没有安装包 | 只出绿色版目录（jpackage 的 app-image），要 msi/exe 安装包需要先装 WiX |
| Windows 11 默认看不到一级菜单 | 系统只给带包标识的 `IExplorerCommand` 扩展开一级菜单；绿色版只能靠「经典菜单」开关绕开，或每次 `Shift + 右键` |
| 没有快捷键体系 | 只有 JSON、文本比对、MyBatis SQL 三页的 `Ctrl + Enter` |
| 无历史记录 / 多语言 | 关闭页面即丢内容；界面文案直接写在代码里 |

## 六、后续建议

按「投入产出比」排序，前四条是投入小、立刻能感知收益的。

### A. 补齐同一依赖下的能力缺口（低成本、高感知）

1. **PDF 扩成一整套页面操作**：压缩（图片重采样）、加密 / 解密、页面旋转与删除、提取图片、加水印。
   现在 PDFBox 已经在依赖里，拆分合并的代码结构也能复用，属于「顺手就能做」。
   其中**压缩**最刚需——扫描件动辄几十 MB，发邮件先卡在这一步。
2. **图片从「看」变成「处理」**：批量压缩（质量 / 最长边）、格式转换（含 WebP）、批量重命名、加水印。
   图片转 PDF 顺带补上 A4 适配与页边距，打印才像样。
3. **哈希页加「校验」与「批量」**：粘贴官方 MD5/SHA256 自动比对（下载文件校验的典型场景），
   以及整个文件夹批量算哈希、导出 CSV。
4. **OCR 输出形态**：现在只有纯文本。补「导出 TXT/MD」「按段落还原」「批量多图」「剪贴板图片直接识别」，
   更进一步做「扫描件 PDF → 可搜索 PDF」，这是 OCR 最值钱的用法。

### B. 提升「每天都想开」的效率设计

5. **全局搜索 / 命令面板（`Ctrl + K`）**：16 个页面靠导航找已经开始变慢，模糊搜索「base64」「拆分」直接跳页。
6. **智能粘贴**：读剪贴板猜内容类型（JSON / Base64 / JWT / 时间戳 / 哈希 / URL），提示「这是 Base64，去解码？」。
   这类工具最爽的瞬间就是「我知道该用哪个功能，只是不想找」。
7. **统一拖放入口**：把 `installFileDrop` 提升到窗口级，按扩展名分派到对应页面，
   同时支持把文件拖到 exe 图标上（命令行扩成 `--open <file>` 而不只是 `--to-pdf`）。
8. **历史记录**：本地存最近 50 条输入 / 输出（可清空），误关页面不丢内容。
9. **任务链**：把「Word → PDF → 合并 → 压缩」串成一次执行。
   现在是一页一件事，真实工作流却常常是三四步。

### C. 强化「大力丸」的差异化

10. **右键菜单继续扩项**：现在右键里只多一个「大力丸 ▸」子菜单，里面是「转 PDF /
    转 Word / 转 Excel / 转 PPT / 提取文本」；下一步可以往同一个子菜单里加「图片转 PDF」
    「计算哈希并复制」「OCR 识别」「压缩图片」——这几项都已有实现，只是没挂到菜单上。
    继续加也不会让右键变长，因为入口始终只有一个。
11. **二维码补场景**：WiFi / vCard / 批量生成（CSV 导入导出 zip）、生成 SVG（印刷用）。
12. **文本小工具补位**：JSON ↔ YAML / CSV、正则测试器、颜色转换、cron 解析。
    其中 **JSON → CSV** 在运营和测试场景几乎天天要用。

### D. 工程与发布

13. **体积**：换掉 Aspose 三件套（44 MB）后 zip 从 134 MB 降到 114 MB（应用层小了近一半，
    但 Java 25 运行时比 21 大：52 → 95 MB，换 Temurin 25 可回落）。再往下的空间在功能上：
    可以做「精简版」（只含文本 + PDF，约 30 MB）与「完整版」两条线，或者把 PPT 引擎改成首次使用时下载。
14. **安装包**：装 WiX 出 msi，或用 Inno Setup 包一层绿色版目录，换来卸载项、文件关联、开机启动。
15. **引擎策略可配置**：设置里给「优先内置引擎 / 优先 LibreOffice」的开关；
    LibreOffice 探测逻辑已经写好，只是没暴露成开关。
16. **UI 自动化冒烟**：190 个测试集中在 `core`，界面靠截图自检。可引入 TestFX 跑「启动 → 逐页切换 → 关键按钮」，
    把现在手写的 `tools/*Check.java` 固化成 CI 步骤。
